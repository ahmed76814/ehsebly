# ميزان الحديد — حاسبة ميزانية الجمالونات والهناجر المعدنية (السوق المصري)

تطبيق ويب احترافي مخصص لورش الحدادة وتصنيع الجمالونات والهناجر في مصر.

## أبرز المميزات
1. **تحديث يومي لأسعار الحديد والصاج في السوق المصري:**
   - يعرض أسعار اليوم للحديد الخفيف (علب وزوايا)، المتوسط (كمر IPE/UPN)، الثقيل (كمر HEA/IPE)، وأنواع الصاج (مجلفن، ملون إيكون، ساندوتش بانل عازل).
   - يتحدث يومياً تلقائياً، مع إمكانية تعديل أسعار اليوم يدوياً لتطابق سعر التاجر الذي تتعامل معه.
2. **حساب هندسي فوري للكميات والميزانية:**
   - أدخل **الطول × العرض (البحر) × الارتفاع** ليحسب لك فوراً:
     - إجمالي الحديد المطلوب بالطن والكيلوجرام (مفصل: أعمدة، جمالونات/مقصات، مدادات، شدادات، بليتات، هالك).
     - إجمالي الصاج بالمتر المربع وعدد الألواح القياسية (6 متر).
     - تكلفة المستلزمات (دهان برايمر وبوية، سلك لحام، مسامير صاج، أنكر بولت، ومزاريب صرف أمطار).
     - مقاسات القطاعات الاسترشادية المقترحة للتنفيذ.
3. **خيارات شاملة للمواصفات:**
   - **نوع الجمالون للسقف:** خفيف للتخزين والمظلات / متوسط للورش والمخازن / ثقيل للمصانع والأحمال العالية.
   - **نوع الحديد:** خفيف (علب وزوايا) / متوسط (كمر IPE) / ثقيل محمّل (HEA/IPE).
   - **نوع الصاج:** مجلفن 0.4 أو 0.5 مم، ملون إيكون 0.5 أو 0.7 مم، ساندوتش بانل 5 سم أو 10 سم.
   - **شكل السقف وتقفيل الأجناب:** هرمي ميلين / ميل واحد / مقوس + سقف فقط أو تقفيل جزئي فوق طوب أو تقفيل كامل.
4. **إضافة المصنعية بضغطة واحدة (لصاحب الورشة):**
   - كل ما يفعله الحداد بعد الحسبة هو إضافة مصنعيته (بالمقطوعية أو بالطن والمتر أو كنسبة مئوية) + النقل والونش إن وجد.
   - خيار لإخفاء تفصيل المصنعية عند الطباعة أو الإرسال للعميل (إظهار الإجمالي الشامل فقط).
5. **مخطط هندسي تفاعلي مباشر (3D + مقطع أمامي):**
   - يتغير الرسم الهندسي مباشرة مع المقاسات ونوع السقف وتقفيل الجوانب.
6. **رابط خاص للعميل + إرسال واتساب + طباعة عرض سعر PDF:**
   - يمكنك إنشاء رابط خاص ترسله للعميل (`?mode=client`) ليدخل مقاساته ويرى ميزانية الخامات ثم يرسل لك الطلب على واتساب برابط جاهز تفتحه وتضيف عليه مصنعيتك فقط!

## طريقة التشغيل
- **الطريقة السريعة (مباشرة):** افتح ملف `index.html` في أي متصفح (يعمل 100% مباشرة بدون أي تثبيت).
- **الطريقة الكاملة مع الخادم اليومي المحلي:** اضغط مرتين على ملف `start-server.bat` (أو شغّل `python server.py`) ثم افتح `http://localhost:8080`.
- **نشر الموقع مجاناً على الإنترنت لإرسال الرابط للعملاء:** ارفع مجلد `mizan-alhadeed` مباشرة على [Netlify Drop](https://app.netlify.com/drop) أو GitHub Pages خلال ثوانٍ لتحصل على رابط دائم ترسله لعملائك على واتساب!
